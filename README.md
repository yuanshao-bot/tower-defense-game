# 🏰 塔防守卫战

一款基于 HTML5 Canvas 的塔防策略游戏，开箱即玩、可离线运行、支持安装为桌面/手机应用（PWA）。

**在线游玩**：[https://yuanshao-bot.github.io/tower-defense-game/tower-defense.html](https://yuanshao-bot.github.io/tower-defense-game/tower-defense.html)

---

## ✨ 游戏特色

- 🎯 **8 种炮台**：机枪、火炮、冰霜、狙击、金矿、毒液、电击、导弹，各有定位
- ⚔️🛡 **双升级路线**：攻击（伤害/射程/攻速）与防御（血量/护甲）独立升级，各 3 级
- 🏰 **炮台可被摧毁**：敌人会攻击范围内的炮台，需要合理分配攻击与防御投资
- 🔧 **修理系统**：花金币修复受损炮台，守住关键防线
- 👹 **5 种敌人**：普通兵、快速兵、坦克、蝙蝠（飞行）、Boss
- 💀 **4 档难度**：简单 / 普通 / 困难 / 地狱，每档独立的最高纪录
- ⏩ **最高 10 倍速**：快节奏推波
- 🔄 **自动下一波**：波次间隔 5 秒自动开战
- 📳 **打击感**：屏幕震动、伤害飘字、爆炸特效
- 📱 **PWA 应用**：可安装到桌面/手机，离线也能玩

## 🎮 玩法说明

1. 选择难度，点击「开始游戏」
2. 从底部工具栏选择炮台（或按 `1-8` 快捷键），点击地图空地建造
3. 点击已建造的炮台可以：
   - 🎯 切换索敌优先级（最前 / 最后 / 最强 / 最弱）
   - ⚔️ 升级攻击（红点）
   - 🛡️ 升级防御（蓝点）
   - 🔧 修理
   - 💰 出售（返还 60%）
4. 敌人会沿道路（地面）或直线航线（飞行）进攻，途中会攻击你的炮台
5. 敌人抵达基地会扣血，血量归零则失败
6. 每 5 波出现 Boss，半血时会召唤小怪
7. 波次之间有 5 秒准备时间，可按 `N` 提前开战获得额外金币

### 快捷键

| 按键 | 功能 |
|------|------|
| `1-8` | 选择炮台 |
| `空格` | 暂停 / 继续 |
| `N` | 提前开始下一波 |
| `Esc` / 右键 | 取消选择 |

## 🚀 本地运行

无需构建，直接用浏览器打开 `tower-defense.html` 即可。

也可以双击 `启动游戏.bat`（Windows）。

### 部署到 GitHub Pages

1. Fork 或克隆本仓库
2. 开启 Settings → Pages → Branch: `master` / `(root)`
3. 访问 `https://你的用户名.github.io/tower-defense-game/tower-defense.html`
